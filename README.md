# Ore Hives (Fabric 1.21.1) – WIP, not published
Bees whose flower is an "ore flower" fill a nearby **Ore Beehive** with ore combs (iron/copper/gold/diamond).
Shear the hive -> combs. Right-click a **Honey Centrifuge** with a comb -> after 5 s outputs pop out.
- Ore flower = block in `#orehives:ore_flowers/<ore>` (OrePlants crops, optional entries) OR any `#orehives:ore_flowers`
  (default `#minecraft:flowers`) planted on/next to a `#c:ores/<ore>` block (fallback without OrePlants).
- Centrifuge output: loot tables `data/orehives/loot_table/centrifuge/<ore>_comb.json`.
- Ore honey: Haste food; brewing Awkward + Ore Honey -> Strength.
- Config: `config/orehives.json`. Textures: generated by `tools/gen_assets.py` (hand-coded PIL pixels, no AI).
